# 搭个伴 · DeepSeek Harness 插件

在自己的 Agent 里寻找摄影、编程、设计、家教等技能合作机会。安装后用邮箱登录，即可查看平台类别和热帖、搜索帖子、保存草稿并发布。

**发帖、搜索和热帖目前免费。** 类别由平台后台统一维护，普通用户不需要创建类别、建站或承担运营工作。

## 安装

需要 DeepSeek Harness 0.2.x 和 Node.js 24.9+。在本机终端执行：

~~~sh
dsh plugin add github:Y1le/dsh-dageban
~~~

也可以在 DeepSeek Harness 的插件安装入口填写 `github:Y1le/dsh-dageban`。原生 JavaScript 包，没有安装时构建脚本。插件通过官方 `@deepseek-ai/dsh-mcp-client` 接入 MCP。开发测试基于 0.2.2-rc.1；其他版本需要自行验证。

## 第一次使用

对 DeepSeek Harness 说：

> 连接搭个伴，看看现在有哪些类别和帖子。

Agent 调用 login 后会提供授权链接。在**运行 Harness 的同一台电脑**的浏览器中打开，用邮箱验证码登录或注册，并允许本插件访问个人资料和帖子。验证码仅填网页，不发给 Agent。

授权后回到 Harness 说“看看热帖”。get_home 一次返回后台开放的类别及当前热帖。远程服务器上的 Harness 暂不支持把浏览器回调转发到本机；请在本机运行本版。

## 使用示例

- “在搭个伴找佛山的摄影合作。”
- “我是男模，在佛山找摄影师，帮我整理并发布合作帖子，时间和报酬待商议。”
- “我要给这条草稿加图片。”
- “查看我还没发布的草稿。”
- “退出搭个伴。”

发帖时缺少必要资料，Agent 才会追问。若要附图，它会给出绑定草稿的上传页，上传完成后再发布。平台没有对应类别时会明确告知，可以先保存草稿。类别是否开放由后台决定，插件没有类别修改工具。

热帖按最近 7 天主动联系帖子的不同用户数排序，重复消息不重复计数；相同人数按发帖时间排序。还没有互动数据时明确展示最新帖子，不伪造点击量或热度。

## 数据与权限

只申请个人资料读取/填写、帖子读取/发布四项权限。不申请后台管理或私信权限。发布结果以服务器返回的帖子 ID 为准；重试不会自动生成新的发帖请求。授权令牌由本机桥接进程保存，不进入模型回复；默认位于 `$DSH_HOME/credentials/dageban`，未设置 DSH_HOME 时使用 `~/.dsh/credentials/dageban`，退出登录会清理本机令牌并尝试撤销远端授权。

~~~sh
node --test test/*.test.mjs
~~~

登录使用 OAuth 授权码与 PKCE；回调只监听 127.0.0.1，校验 state、issuer 和 Host。后端继续校验身份、scope、类别、草稿版本、发布规则和图片归属。公开仓库只含接入代码，不含后端源码、生产配置或用户数据。
